# AVANZA · Crédito con claridad

Sitio web estático de demostración para AVANZA.

## Alcance

Incluye simulador, CAT, cronograma, calendario con feriados, solicitud de prueba, evaluación orientativa, panel interno demo, jurídico, cobranza, Gobierno, antifraude local, estado de cuenta simulado y hoja de ruta de producción.

**Acceso demo al panel:** `avanza2026`

## Importante

Los datos, tasas, contratos, testimonios, contactos y controles regulatorios son de ejemplo. No es una oferta de crédito, no genera obligaciones y requiere backend, seguridad, integraciones certificadas y revisión legal antes de operar.

El sitio se publica como HTML estático. Las solicitudes y registros se conservan únicamente en el navegador mediante `localStorage`.
